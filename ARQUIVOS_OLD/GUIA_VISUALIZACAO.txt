🚀 COMO VISUALIZAR LOCALMENTE
==============================

Opção 1: Abrir Direto
---------------------
1. Abra a pasta do projeto
2. Clique duplo em "index.html"
3. O site abrirá no navegador padrão

Opção 2: Com Live Server (VS Code)
-----------------------------------
1. Instale a extensão "Live Server"
2. Clique com botão direito em index.html
3. Selecione "Open with Live Server"
4. Abrirá em http://localhost:5500

Opção 3: Por Terminal (Python)
------------------------------
cd "g:/Tudo/MEU-SISTEMA/SOMOS_UNN"
python -m http.server 8000
# Acesse http://localhost:8000

Opção 4: Por Terminal (Node.js)
-------------------------------
npx http-server
# Acesse http://localhost:8080

🖼️ COMO SUBSTITUIR IMAGENS
=========================

As imagens usam URLs Unsplash. Para customizar:

1. Encontre a tag <img>
2. Altere o atributo src="..."
3. Use qualquer URL de imagem
4. Recomenda-se: unsplash.com (grátis, sem limites)

Exemplo:
<img src="https://images.unsplash.com/photo-XXXXXXXXXX?crop=entropy&cs=tinysrgb&fit=max&fm=jpg&q=80&w=1080"
    alt="Descrição">

🎯 COMO CUSTOMIZAR CORES
=========================

1. Localize a tag <style>
2. Encontre as variáveis de cor
3. Altere os valores HEX ou RGB
4. Exemplo:
   background: linear-gradient(135deg, #NOVO_COR_1 0%, #NOVO_COR_2 100%);

Principais seções de cor:
- .btn-primary { background: gradient }
- .text-gradient { background: gradient }
- .section-title::after { background: gradient }

🔧 COMO CUSTOMIZAR TEXTO
========================

1. Procure o texto que deseja alterar
2. Localize dentro das tags HTML
3. Edite o conteúdo
4. Exemplo:
   <h1>Novo Título Aqui</h1>

Principais seções de texto:
- <h1> - Títulos principais
- <p> - Parágrafos
- <span> - Textos inline
- <a> - Links
