📦 INSTRUÇÕES PARA ADICIONAR A LOGO
=====================================

LOCAL DA LOGO:
→ Pasta: img/
→ Arquivo: logo.png

DIMENSÕES RECOMENDADAS:
✓ Largura: 240px
✓ Altura: 70px
✓ Proporção: 240:70

FORMATO SUGERIDO:
✓ PNG com fundo transparente
✓ SVG também é compatível (substitua .png por .svg)

ONDE A LOGO APARECE NO SITE:

1. HEADER DESKTOP (index.html e portal.html)
   - Localização: Navegação superior esquerda
   - Altura exibida: 56px (14rem)
   - A proporção 240:70 é mantida automaticamente

2. MENU MOBILE/SIDEBAR (index.html e portal.html)
   - Localização: Topo do menu lateral esquerdo
   - Altura exibida: 64px (16rem)
   - A proporção 240:70 é mantida automaticamente

COMO ADICIONAR:

1. Prepare seu arquivo de logo em PNG (240x70px)
2. Renomeie para: logo.png
3. Coloque na pasta: img/
4. Pronto! A logo aparecerá automaticamente em ambos os sites

CAMINHO COMPLETO:
→ g:\Tudo\MEU-SISTEMA\SOMOS_UNN\img\logo.png

COMPATIBILIDADE:
✓ Todos os navegadores modernos
✓ Totalmente responsivo
✓ Otimizado para mobile e desktop

DICAS:
- Use PNG com transparência para melhor resultado
- Mantenha o arquivo em 240x70px para melhor qualidade
- A logo será redimensionada automaticamente conforme a altura do container
