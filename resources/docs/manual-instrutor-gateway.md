# Manual do Instrutor: Configuração de Gateway de Pagamento

## Como configurar seu gateway para receber pagamentos

1. Acesse o menu lateral "Minhas Configurações de Pagamento" no painel.
2. Preencha os campos de credenciais do MercadoPago e/ou PagSeguro:
   - **MercadoPago**: Public Key e Access Token
   - **PagSeguro**: E-mail e Access Token
3. Clique em "Testar Conexão" para validar as credenciais.
4. Marque "Ativar" para o gateway desejado.
5. Clique em "Salvar configurações".

> Suas vendas só serão processadas se o gateway estiver corretamente configurado e ativado.

## Dúvidas frequentes
- **Onde encontro minhas credenciais?**
  - No painel do MercadoPago/PagSeguro, em "Credenciais".
- **Posso usar ambos os gateways?**
  - Sim, configure e ative os dois se desejar.
- **Como funciona a comissão da plataforma?**
  - A comissão é descontada automaticamente conforme o valor configurado pelo administrador.

Em caso de dúvidas, entre em contato com o suporte da plataforma.
