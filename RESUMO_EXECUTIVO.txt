🚀 COMO USAR
=============

OPÇÃO 1: Abrir Direto
1. Clique duplo em index.html
2. Site abre no navegador

OPÇÃO 2: Com Live Server (VS Code)
1. Instale extensão Live Server
2. Clique direito > Open with Live Server
3. Site abre com auto-reload

OPÇÃO 3: Terminal Python
cd "g:/Tudo/MEU-SISTEMA/SOMOS_UNN"
python -m http.server 8000
# Acesse http://localhost:8000

OPÇÃO 4: Terminal Node.js
npx http-server
# Acesse http://localhost:8080

🎯 CUSTOMIZAÇÕES
=================

ADICIONAR LOGO:
1. Prepare imagem 240x70px (PNG com fundo transparente)
2. Salve como img/logo.png
3. Substitua arquivo existente
4. Recarregue o navegador

MUDAR CORES:
1. Abra index.html em editor
2. Localize <style> section
3. Altere valores HEX para a paleta final:
   #5B21B6 → #D946EF → #2563EB (roxo→magenta→azul)
4. Salve e recarregue

EDITAR TEXTOS:
1. Encontre o texto na página
2. Edite o conteúdo entre tags
3. Exemplo: <h1>Novo Texto</h1>
4. Salve e recarregue

SUBSTITUIR IMAGENS:
1. Procure tag <img src="...">
2. Altere URL para sua imagem
3. Recomenda-se Unsplash (grátis)
4. Salve e recarregue
