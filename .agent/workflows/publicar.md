---
description: Publicar alterações no git com mensagem humanizada e atualização do README
---

1. Ler o arquivo `README.md` para entender o estado atual.
2. Atualizar o `README.md` com um resumo das alterações recentes (features, correções, melhorias).
3. Adicionar todos os arquivos ao git: `git add .`
4. Commitar com uma mensagem humanizada e descritiva em português. Exemplo: `Feature: Implementação do sistema de permissões e conexões automáticas`.
5. Enviar para o repositório remoto: `git push origin main`
6. Notificar o usuário que a publicação foi realizada com sucesso.
